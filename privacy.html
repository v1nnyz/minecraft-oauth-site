Como funciona o uso do Google Drive pelo projeto pessoal Minecraft Backup.

Em resumo: o aplicativo automatiza backups de um servidor Minecraft para uma conta Google Drive autorizada pelo próprio usuário. Não vende informações nem oferece serviços comerciais.

01 / PROPÓSITO

Finalidade do aplicativo

O Minecraft Backup é um projeto pessoal e não comercial que utiliza Rclone e GitHub Actions para transferir cópias de segurança de um servidor Minecraft hospedado no Altare para a conta Google Drive autorizada.

Este site é apenas informativo: ele não solicita login, não executa os backups diretamente e não possui formulário para envio de arquivos.

02 / DADOS

Dados utilizados

A automação trata arquivos de backup do servidor, que podem conter mundos salvos, configurações, dados de jogo e informações de jogadores presentes nesses arquivos.

Para se comunicar com o Google Drive, a automação utiliza credenciais OAuth autorizadas pelo titular da conta. O acesso é configurado para operar nos arquivos disponibilizados ou criados pelo aplicativo, conforme o escopo concedido.

03 / INFRAESTRUTURA

Serviços envolvidos

O processo depende de três serviços externos: Altare (origem dos arquivos), GitHub Actions (execução temporária da automação) e Google Drive (armazenamento dos arquivos). Esses provedores processam as informações necessárias ao funcionamento de seus respectivos serviços, segundo suas próprias políticas.

O projeto não comercializa os dados nem os disponibiliza publicamente.

04 / ARMAZENAMENTO

Armazenamento e retenção

Os backups são guardados na conta Google Drive autorizada. A rotina foi configurada para criar uma nova cópia semanalmente e manter os quatro backups mais recentes, removendo os anteriores de modo permanente quando exceder esse limite.

Os arquivos também podem ser excluídos manualmente pelo titular da conta. A disponibilidade de espaço depende do plano de armazenamento utilizado no Google Drive.

05 / CONTROLES

Segurança e acesso

As credenciais utilizadas pela automação são armazenadas como segredos no repositório privado do GitHub, e não no código público deste site. O acesso deve ser restrito à conta do responsável pelo projeto.

Esta página não utiliza cookies próprios de rastreamento, formulários de captura nem serviços de análise de visitantes. O armazenamento dos backups não elimina a necessidade de testar a restauração periodicamente.

06 / CONTROLE DO USUÁRIO

Como revogar o acesso

O titular pode remover a autorização concedida ao aplicativo em sua conta Google a qualquer momento. Isso interrompe novas operações autenticadas com o Drive, mas não exclui automaticamente os backups já armazenados.
