Política de Privacidade

O Minecraft Backup é um aplicativo de uso pessoal criado para automatizar backups de um servidor Minecraft no Google Drive.

1. Finalidade

Este aplicativo é utilizado exclusivamente para criar, consultar, enviar e organizar arquivos de backup gerados a partir do servidor Minecraft do usuário.

2. Dados acessados

O aplicativo pode acessar apenas os arquivos necessários para a operação de backup dentro da conta Google autorizada pelo usuário.

3. Armazenamento

Os backups são armazenados somente no Google Drive do próprio usuário autorizado. O aplicativo não realiza compartilhamento público desses arquivos.

4. Compartilhamento de dados

Nenhum dado pessoal é vendido, distribuído ou compartilhado com terceiros para fins comerciais.

5. Segurança

O acesso ao Google Drive é feito mediante autorização do próprio usuário, podendo ser revogado a qualquer momento nas configurações de segurança da conta Google.

6. Revogação de acesso

O usuário pode remover o acesso do aplicativo diretamente em sua conta Google, caso deseje interromper a integração.

7. Contato

Este aplicativo é de uso pessoal e sem fins comerciais.
